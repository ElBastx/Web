## 📁 Projets

### 🕐 Horloge dynamique — `js/horloge_dynamique/`

Horloge temps réel affichant l'heure au format `HH:MM:SS`, mise à jour chaque seconde.

**Notions travaillées :**
- Manipulation du DOM (`document.getElementById`, `textContent`)
- Objet `Date` et formatage avec `padStart()`
- Exécution périodique avec `setInterval()`

**Lancer :** ouvrir `js/horloge_dynamique/clock.html` dans un navigateur.

## 🛠️ Technologies

HTML · JavaScript (vanilla, sans framework)
